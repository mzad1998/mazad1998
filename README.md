# مزاد الصيانة

تطبيق عميل عراقي مستقل مبني بـ React Native وExpo Router. يحاكي إرسال طلبات صيانة ومنتجات سيارات، واستلام عروض من ورش خيالية، والمقارنة والمحادثة وقبول عرض واحد. لا توجد معاملات أو رسائل أو جهات أو مدفوعات حقيقية.

## التشغيل

```bash
npm install
npm start                 # امسح QR بواسطة Expo Go
npm run android           # Android
npm run ios               # iOS/macOS
npm run web               # معاينة الويب
```

رمز OTP التجريبي: **1234**. يتطلب Expo Go إصدار SDK 54 متوافقاً. المنصات المستهدفة iOS وAndroid والويب، مع بقاء اختبار اختيار الصور والروابط الفعلية مطلوباً على جهاز.

## الفحوص

```bash
npm run typecheck
npm run lint
npx expo-doctor
npm run export:web
```

## البنية
- `app/`: مسارات وشاشات Expo Router.
- `components/`: عناصر واجهة RTL قابلة لإعادة الاستخدام.
- `types/`: نماذج المجال الصارمة.
- `services/`: حالة التطبيق وقواعد الإرسال/القبول/المحادثة.
- `storage/`: بوابة AsyncStorage واحدة مع parsing آمن وقيم افتراضية.
- `mocks/`: الورش الخيالية، بينما يولد `services/domain.ts` عروضاً متنوعة.
- `constants/`: الهوية البصرية والتسميات العربية.

## التخزين والمحاكاة
تُحفظ لقطة `AppData` ذات إصدار واحد محلياً، وتشمل الجلسة والعميل والسيارات والطلبات والعروض والقبول والمحادثات والإشعارات وتذاكر الدعم والتفضيلات. تلف JSON يعيد حالة آمنة بدلاً من تعليق splash. أدوات الإعدادات تمسح الإشعارات أو المحادثات أو كل البيانات. تسجيل الخروج يبقي البيانات؛ حذف الحساب يزيلها.

OTP والورش والعروض والردود والإشعارات كلها محاكاة. أرقام الورش خيالية، ولا توجد خدمة SMS أو backend أو دفع. اختيار الصور محلي وقد تختلف صلاحياته حسب المنصة.

## استبدال التخزين مستقبلاً
واجهة الحالة تحصر القراءة والكتابة في طبقة الخدمات؛ يمكن تعريف repository بعيد يطبق عمليات `load/save` ومعامل قبول ذري، ثم حقنه في `AppProvider` دون إعادة بناء الشاشات. عند استخدام Supabase مستقبلاً يجب نقل قيد «عرض واحد لكل طلب» إلى unique constraint ومعاملة خادمية، مع إبقاء التحقق المحلي لتحسين UX.

## القرارات والقيود
التفاصيل التي يدخلها العميل حقول نص يدوية بلا قواعد سيارات أو pickers. التصميم يعتمد StyleSheet وأصول نصية خفيفة. لا يمكن بيئياً ضمان فتح تطبيق الهاتف/واتساب أو سلوك أذونات معرض الصور دون جهاز، ولذلك تفشل هذه الإجراءات برسالة عربية آمنة. راجع `SPECIFICATION.md` للقواعد و`IMPLEMENTATION_CHECKLIST.md` للحالة الفعلية للفحوص.
